# DJ Mix – Bal des CM2 2026

Interface d'assistant DJ pour enchaîner les musiques du Bal des CM2.

## Fonctionnalités

- **Bibliothèque** de 47 morceaux classés par catégorie (Anime, K-Pop, Pop, French, Gaming, Dance)
- **File d'attente** avec drag-and-drop pour réordonner les morceaux
- **Now Playing** : morceau en cours avec navigation précédent/suivant
- **Recherche** et **filtres** par catégorie
- **Shuffle** et vidage rapide de la file
- **Liens YouTube Music** pour chaque morceau
- **Sauvegarde locale** (localStorage) de l'état DJ

## Utilisation

Ouvrir `index.html` dans un navigateur. Aucune dépendance externe requise.
