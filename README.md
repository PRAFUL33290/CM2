# OBJECTIF DU SITE

Ce site est un véritable assistant DJ pour le Bal des CM2.

Il doit permettre :

* Organiser la soirée
* Gérer les playlists
* Afficher les musiques demandées
* Suivre les animations
* Afficher le déroulement de la soirée
* Être utilisé sur ordinateur portable
* Être affiché sur une télévision géante
* Respecter l'univers Japon / Manga / Anime / K-Pop

Le site doit être utilisable en temps réel pendant l'événement.
